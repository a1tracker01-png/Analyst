# ⚡ ViralRadar AI — Instagram Competitor Analysis for Tech & AI Creators

A powerful Instagram Competitor Intelligence & Viral Trend Replication dashboard designed specifically for content creators in the **Tech and Artificial Intelligence** niche.

Built to run **100% on free-tier, public endpoints, and open-source tooling** with permanent zero-cost operation.

---

## 🚀 Key Features

1. **Competitor Management Dashboard:**
   - Dynamically track, add, and remove Instagram competitor usernames.
   - Live metrics (followers, average views, engagement rate %).
   - Persistent local JSON storage.

2. **Advanced Reels Filtering & Sorting:**
   - **Timeframes:** Past 24 Hours, Past 2 Days (48h), Past 4 Days (96h), Past 1 Week (7d), All Time.
   - **Sorting Modes:** Most Popular (Views), Velocity (Views/Hour), Engagement Rate %, Viral Outlier Multiplier, Newest First.
   - Instant search across captions, AI models, and topics.

3. **Viral Alert / Fast-Boom Detector:**
   - Real-time detection of reels picking up rapid momentum in short windows.
   - Velocity calculations ($views / age$) and outlier scoring relative to creator baseline.
   - **30-Second Video Replication Script Generator** with hook breakdown and audio recommendations.

4. **Fast-Growing Creator Discovery (Tech & AI):**
   - Curated directory across sub-niches: *AI Agents & Automation, Open Source LLMs, Prompt Engineering, AI Coding/Cursor, Robotics, Creative AI*.
   - 7-day follower growth rates ($+14\%$ to $+31\%$).
   - One-click addition to competitor watchlist.

5. **100% Free-Tier & Zero-Cost Architecture:**
   - Public Instagram web endpoints with header rotation.
   - Resilient fallback cache to protect against rate limits.
   - Zero subscription fees or credit cards needed.
   - Built-in CSV export.

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** Vanilla HTML5, Vanilla CSS3 (Obsidian Dark, Glassmorphism, Micro-animations), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (Plus Jakarta Sans, JetBrains Mono)
- **Data Persistence:** JSON Flat-File Store

## 📦 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
npm install
```

### 2. Run the Application
```bash
npm start
```

### 3. Open in Browser
Navigate to **`http://localhost:3000`**.
